# キーマップ一覧

## 表記

| 表記 | 意味 |
| --- | --- |
| `<leader>` | `Space` |
| `<C-x>` / `<S-x>` / `<M-x>` | Ctrl+x / Shift+x / Alt(Option)+x |
| `<CR>` / `<BS>` / `<Esc>` | Enter / Backspace / Escape |
| モード `n` / `v` / `i` / `t` / `o` | ノーマル / ビジュアル / 挿入 / ターミナル / オペレータ待機（`d` や `y` の直後） |

- `timeoutlen` は 400ms です。`<leader>` を押して止まると which-key が候補を表示します。
- 「LSP」と書いたキーは LSP が接続されたバッファだけ、「Git」と書いたキーは Git 管理下のファイルだけで使えます。

`<leader>` 配下の割り当て:

| プレフィックス | 用途 |
| --- | --- |
| `<leader>f` | 検索（Telescope） |
| `<leader>g` | Git（Diffview / Telescope） |
| `<leader>h` | Git hunk（gitsigns） |
| `<leader>c` | コード / Claude Code |
| `<leader>l` | LSP |
| `<leader>b` | バッファ |
| `<leader>t` | タブページ |
| `<leader>x` | Hex 編集 |
| `<leader>u` | UI の切り替え |

## 基本

定義: `lua/config/keymaps.lua`

| キー | モード | 動作 |
| --- | --- | --- |
| `<Esc>` | n | 検索ハイライトを消す |
| `<leader>w` | n | 保存 |
| `<leader>q` | n | ウィンドウを閉じる（未保存なら確認）`:confirm quit` |
| `<leader>Q` | n | すべて強制終了 `:qa!`（**未保存の変更は破棄**） |
| `Y` | n | 行末までヤンク |
| `n` / `N` | n | 次 / 前の検索結果へ（画面中央に表示） |
| `<C-d>` / `<C-u>` | n | 半ページ下 / 上（画面中央に表示） |
| `<` / `>` | v | インデントを減らす / 増やす（選択を維持） |
| `J` / `K` | v | 選択行を下 / 上へ移動 |
| `<leader>p` | v | 選択範囲をクリップボードの内容で置き換える（レジスタを上書きしない）。ノーマルモードでは何も起きない |
| `<leader>d{motion}` | n, v | ヤンクせずに削除（例: `<leader>dd`、`<leader>diw`） |
| `<Esc><Esc>` | t | ターミナルモードを抜ける |

クリップボードはシステムと共有です（`clipboard=unnamedplus`）。

## ウィンドウ・バッファ・タブ

| キー | モード | 動作 |
| --- | --- | --- |
| `<C-h>` / `<C-j>` / `<C-k>` / `<C-l>` | n | 左 / 下 / 上 / 右のウィンドウへ移動 |
| `<C-Up>` / `<C-Down>` | n | ウィンドウの高さを +2 / -2 |
| `<C-Left>` / `<C-Right>` | n | ウィンドウの幅を -2 / +2 |
| `<S-h>` / `<S-l>` | n | 前 / 次のバッファ（bufferline の並び順）。標準の `H` / `L`（画面上端 / 下端へ移動）を上書き |
| `<leader>bd` | n | バッファを閉じる（サイドバーのレイアウトを崩さない） |
| `<leader>bo` | n | 現在以外のバッファをすべて閉じる |
| `<leader>bD` | n | バッファを強制的に閉じる（未保存の変更は破棄） |
| `<leader>tc` | n | タブページを閉じる |
| `<leader>tD` | n | タブ内の各ウィンドウのバッファを削除 `:windo bdelete` |

バッファタブ（bufferline）のマウス操作: 左クリックで切り替え、右クリックまたは閉じるアイコンで閉じる（`bdelete!` なので**未保存の変更は破棄**されます）。

| --- | --- | --- |
| `<leader>ff` | n | ファイル検索（隠しファイルを含む。Git で変更のあるファイルに `●` と黄色表示） |
| `<leader>fF` | n | ファイル検索（通常版） |
| `<leader>fg` | n | 文字列検索。rg のオプションを付けられる（例: `foo -tlua`、`"foo bar" -g "*.nix"`） |
| `<leader>fG` | n | 文字列検索（単語一致 `-w`） |
| `<leader>fi` | n | 文字列検索（大文字小文字を区別しない `-i`） |
| `<leader>fI` | n | 文字列検索（大文字小文字を区別する `-s`） |
| `<leader>fw` | n | カーソル下の単語で検索 |
| `<leader>fW` | n | カーソル下の単語で検索（単語一致） |
| `<leader>/` | n | 現在のバッファ内をあいまい検索 |
| `<leader>fb` | n | 開いているバッファ |
| `<leader>fr` | n | 最近開いたファイル |
| `<leader>fh` | n | ヘルプ |
| `<leader>fc` | n | コマンド |
| `<leader>fk` | n | キーマップ |
| `<leader>fd` | n | 診断（エラー・警告） |
| `<leader>fs` | n | シンボル（現在のファイル） |
| `<leader>fS` | n | シンボル（ワークスペース全体） |
| `<leader>ft` | n | TODO / FIXME などのコメント |
| `<leader>gc` | n | Git コミット |
| `<leader>gs` | n | Git status（ファイルアイコン付き） |

Telescope の中:

| キー | モード | 動作 |
| --- | --- | --- |
| `<C-j>` / `<C-k>` | i | 次 / 前の候補 |
| `<CR>` | i, n | 開く |
| `<C-v>` / `<C-x>` / `<C-t>` | i, n | 縦分割 / 横分割 / 新しいタブで開く |
| `<Tab>` | i, n | 選択を切り替えて次へ（複数選択） |
| `<C-a>` | i, n | 選択中（なければカーソル位置）のファイルを Claude Code に送る |
| `<C-q>` | i, n | 結果を quickfix に送る |
| `<C-u>` / `<C-d>` | i, n | プレビューをスクロール |
| `<C-/>` | i | キー一覧を表示 |
| `<Esc>` | i | 閉じる |

文字列検索（`<leader>fg` / `fG` / `fi` / `fI`）の中では、次のキーが上の表より優先されます:

| キー | モード | 動作 |
| --- | --- | --- |
| `<C-q>` | i | 入力をクォートする（あとに rg のオプションを続けられる） |
| `<C-t>` | i | クォートして ` --type=` を付ける |
| `<C-g>` | i | クォートして ` --iglob ` を付ける |
| `<C-Space>` | i | 今の結果をさらにあいまい検索で絞り込む |

## LSP

LSP が接続されたバッファだけで有効です。定義: `lua/plugins/lsp.lua`

| キー | モード | 動作 |
| --- | --- | --- |
| `gd` | n | 定義へ移動 |
| `gD` | n | 宣言へ移動 |
| `gr` | n | 参照一覧 |
| `gi` | n | 実装へ移動。標準の `gi`（最後に挿入した位置で挿入）を上書き |
| `gt` | n | 型定義へ移動。標準の `gt`（次のタブページ）を上書き |
| `K` | n | ホバー（ドキュメント表示） |
| `<leader>ls` | n | シグネチャヘルプ |
| `<leader>rn` | n | シンボル名を変更 |
| `<leader>la` | n, v | コードアクション |
| `]d` / `[d` | n | 次 / 前の診断へ移動（内容をフロート表示） |
| `<leader>ld` | n | カーソル位置の診断を表示 |
| `<leader>cl` | n | `:LspInfo`（**Neovim 0.12 ではこのコマンドがないため動作しない**。代わりに `:checkhealth vim.lsp`） |

- カーソルを 250ms 止めると、ホバーが自動で表示されます。バッファごとに止めるには `:let b:disable_autohover = 1`。
- `gr` を押すと、実行まで 0.4 秒待ちます（Neovim 標準の `grr` / `grn` などと先頭が同じため）。

## 補完（nvim-cmp）

| キー | モード | 動作 |
| --- | --- | --- |
| `<C-Space>` | i | 補完を表示 |
| `<Tab>` / `<S-Tab>` | i | 次 / 前の候補。補完が出ていないときはスニペットの次 / 前の位置へ、それもなければ通常の Tab |
| `<C-n>` / `<C-p>`、`<Down>` / `<Up>` | i | 次 / 前の候補 |
| `<CR>` | i | 選択中の候補を確定（何も選択していなければ普通の改行） |
| `<C-y>` | i | 確定 |
| `<C-e>` | i | 補完を閉じる |
| `<C-b>` / `<C-f>` | i | ドキュメントをスクロール |
| `<M-e>` | i | Fast Wrap: 直後のテキストを閉じ括弧で囲む（nvim-autopairs） |

コマンドライン（`:` / `/` / `?`）では `<Tab>` / `<S-Tab>` / `<C-n>` / `<C-p>` で候補を選び、`<C-y>` で確定、`<C-e>` で閉じます。

## Claude Code

定義: `lua/plugins/claude.lua`

| キー | モード | 動作 |
| --- | --- | --- |
| `<leader>cc` | n | Claude Code の表示 / 非表示（右側 35%） |
| `<leader>cF` | n | Claude のウィンドウへフォーカス（フォーカス中なら隠す） |
| `<leader>cR` | n | 過去のセッションを選んで再開（`--resume`） |
| `<leader>cC` | n | 直前のセッションを続ける（`--continue`） |
| `<leader>cb` | n | 現在のファイルをコンテキストに追加 |
| `<leader>cs` | v | 選択範囲を送る |
| `<leader>cs` | n | 現在の行を送る（エクスプローラーではファイルを送る） |
| `<leader>ca` | n | Claude が提案した差分を承認 |
| `<leader>cd` | n | Claude が提案した差分を拒否 |

Claude のウィンドウの中:

| キー | モード | 動作 |
| --- | --- | --- |
| `<S-CR>` | t | 送信せずに改行 |
| `<Esc><Esc>` | t | ノーマルモードへ（スクロール・コピー用） |
| `i` / `a` | n | 入力に戻る |
| `q` | n | Claude のウィンドウを隠す |
| `gf` | n | カーソル下のファイルを開く |

差分の扱い:

- Claude が編集を提案すると、今のタブに縦分割で差分が開きます
- 承認: `<leader>ca` または差分バッファで `:w`（承認すると差分は自動で閉じます）
- 拒否: `<leader>cd`、または差分のウィンドウを閉じる
